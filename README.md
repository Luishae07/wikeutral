# Wikeutral

A website that shows the live Wikeutral wiki. It is one static page (`index.html`): it reads the wiki's current tunnel address
from the Groundcheck repo, then loads articles, search and pictures from the wiki through that tunnel. If the tunnel is down, the page says so.

Site: https://Luishae07.github.io/wikeutral/

`wikuse` is a small `sh` script to read the wiki from the command line (`curl -O https://Luishae07.github.io/wikeutral/wikuse`).
